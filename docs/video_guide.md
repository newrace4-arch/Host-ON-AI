# 발표영상 제작 가이드 (초보자용)

> 9/4 작성. 10/7 대본초안 → 10/9 최종본+녹화 → 10/10 편집+제출 순서로
> 활용. 오늘(9/5) 작업 마무리 후 여유 있을 때 참고.

## 1. 전체 흐름 (가장 쉬운 방법)

```
대본 작성 → 화면 녹화(내레이션 동시) → 간단 편집(자막/전환) → 렌더링
```

**핵심 원칙: 화면녹화 + 마이크 내레이션을 "동시에" 하면 편집이 훨씬
쉬워집니다.** 따로 찍어서 나중에 맞추려 하면 초보자에겐 오히려 더
어렵습니다.

## 2. 추천 도구 (전부 무료)

| 용도 | 도구 | 이유 |
|---|---|---|
| **화면+음성 동시 녹화** | **OBS Studio** | 완전 무료·오픈소스, Windows/Mac 다 지원, 실제 화면+마이크 동시녹화 표준 도구 |
| 간단 대안(설치 귀찮으면) | Windows 기본 **캡처 도구**(`Win+Alt+R`) 또는 PowerPoint 자체 "화면 녹화" 기능 | 설치 없이 바로 가능, 다만 편집기능은 약함 |
| **자막/전환/BGM 편집** | **Canva**(온라인, 무료) 또는 **VEED.io**(온라인, 회원가입도 불필요) | 브라우저에서 바로 편집 가능, 초보자용 UI로 쉬움 |

**제 추천**: OBS로 녹화 → Canva나 VEED에 업로드해서 자막·전환만 살짝 입히기. 이 조합이 초보자에게 가장 무난합니다.

## 3. 실전 순서 (10/9~10/10 실제로 하실 일)

### 10/7 — 대본 초안
- 화면 전환 순서만 대략 적기: "로그인→대시보드→예약생성→AI응대→정산" 식으로 흐름만
- 각 장면에서 무슨 말을 할지 1~2줄씩만(완벽한 문장 아니어도 됨)

### 10/9 — 최종본 확정 + 녹화
1. 10/7 초안을 실제 완성된 화면에 맞게 다듬기(화면 캡처하면서 문구 수정)
2. **OBS 켜고 화면+마이크 동시 녹화 시작**
3. 대본 보면서 실제 화면 조작하며 설명 — **한 번에 완벽하지 않아도 됨, 이어서 다음날 편집 때 자르면 됨**
4. 여러 번 나눠서 찍어도 무방(장면별로 끊어서 여러 개 파일로 찍고 나중에 이어붙이기)

### 10/10 — 편집 + 제출
1. 아침에 어제 녹화분 다시 보고 재촬영 필요한 부분만 다시 찍기
2. Canva/VEED에 업로드 → 자막 자동생성 기능 활용(있으면 편함) → 전환효과 살짝
3. 최종 렌더링(내보내기) → 용량/포맷 확인 → 제출

## 4. 초보자가 자주 하는 실수 (미리 피하기)

- **처음부터 완벽하게 한 번에 찍으려 하지 않기** — 장면별로 끊어서 여러 번 찍는 게 훨씬 쉽습니다
- **마이크 위치**: 노트북 내장마이크도 충분합니다, 너무 걱정 안 하셔도 됨
- **배경음악은 선택사항**입니다 — 없어도 전혀 문제없고, 오히려 데모영상은 없는 게 더 깔끔한 경우도 많습니다
- **자막은 자동생성 기능부터 써보기** — Canva/VEED 둘 다 자동 자막 기능이 있어서, 완벽하지 않아도 초안으로 쓰고 수정만 하면 훨씬 빠릅니다

## 5. 시간 배분 참고

- 녹화(10/9): 실제 촬영 자체는 1~2시간이면 충분(장면별로 끊어 찍으면)
- 편집(10/10): 자막/전환만 입히는 수준이면 1~2시간이면 충분

**너무 퀄리티에 압박받지 마세요** — 데모 영상은 "화면이 잘 보이고 설명이 명확한지"가 핵심이지, 화려한 편집이 핵심이 아닙니다.
