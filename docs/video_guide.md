> 9/4 작성. 10/7 대본초안 → 10/9 최종본+녹화 → 10/10 편집+제출 순서로
> 활용. 오늘(9/5) 작업 마무리 후 여유 있을 때 참고.
>
> **편집도구·마이크 세부설정의 SSOT는 `docs/video_recording_setup.md`다.**
> 이 문서는 전체 흐름·대본 관점의 초보자용 가이드이고, 설정값이 서로
> 다르게 보이면 항상 `video_recording_setup.md`가 우선한다.

## 1. 전체 흐름 (가장 쉬운 방법)

```
대본 작성 → 화면 녹화(내레이션 동시) → 간단 편집(자막/전환) → 렌더링
```

**핵심 원칙: 화면녹화 + 마이크 내레이션을 "동시에" 하면 편집이 훨씬
쉬워집니다.** 따로 찍어서 나중에 맞추려 하면 초보자에겐 오히려 더
어렵습니다.

## 2. 추천 도구 (전부 무료)

| 용도 | 도구 | 이유 |
|---|---|---|
| **화면+음성 동시 녹화** | **OBS Studio** | 완전 무료·오픈소스, Windows/Mac 다 지원, 실제 화면+마이크 동시녹화 표준 도구 |
| 간단 대안(설치 귀찮으면) | Windows 기본 **캡처 도구**(`Win+Alt+R`) 또는 PowerPoint 자체 "화면 녹화" 기능 | 설치 없이 바로 가능, 다만 편집기능은 약함 |
| **자막/전환 편집** | **Clipchamp**(Windows 11 내장, 무료) | 무료 1080p 워터마크 없음, 로컬 파일 직접 편집(업로드 불필요) |
| 편집 백업 도구 | **Shotcut** | Clipchamp 내보내기 실패 시 대체(OpenShot 아님 — 크래시 이력) |

**제 추천**: OBS로 녹화 → Clipchamp에서 자막·전환만 살짝 입히기.

## 3. 실전 순서 (10/9~10/10 실제로 하실 일)

### 10/7 — 대본 초안
- 화면 전환 순서만 대략 적기: "로그인→대시보드→예약생성→AI응대→정산" 식으로 흐름만
- 각 장면에서 무슨 말을 할지 1~2줄씩만(완벽한 문장 아니어도 됨)

> 10/7 작업 전 `docs/video_recording_setup.md` 4절(실행 계획)을 먼저 확인할 것
> — Clipchamp 내보내기 게이트 테스트가 거기 있다.

### 10/9 — 최종본 확정 + 녹화
1. 10/7 초안을 실제 완성된 화면에 맞게 다듬기(화면 캡처하면서 문구 수정)
2. **OBS 켜고 화면+마이크 동시 녹화 시작**
3. 대본 보면서 실제 화면 조작하며 설명 — **한 번에 완벽하지 않아도 됨, 이어서 다음날 편집 때 자르면 됨**
4. **구간별로 나눠서 찍기가 원칙 — 통짜로 한번에 찍지 않는다.**
   구간 4분할: 로그인+대시보드 / 예약생성 / AI응대 / 청소+정산
   (구간당 3~4분). NG가 나도 해당 구간만 다시 찍으면 된다.
   → 근거와 목표길이는 `docs/video_recording_setup.md` 4절 참조

### 10/10 — 편집 + 제출
1. 아침에 어제 녹화분 다시 보고 재촬영 필요한 부분만 다시 찍기
2. Clipchamp로 열기 → 자막 자동생성 기능 활용(있으면 편함) → 전환효과 살짝
3. 최종 렌더링(내보내기) → 용량/포맷 확인 → 제출

## 4. 초보자가 자주 하는 실수 (미리 피하기)

- **처음부터 완벽하게 한 번에 찍으려 하지 않기** — 장면별로 끊어서 여러 번 찍는 게 훨씬 쉽습니다
- **마이크**: 노트북 내장 마이크로도 짧은 테스트는 가능하지만, 10분 내외의 실제 나레이션엔 유선 헤드셋/USB 마이크를 권장합니다(상세 근거는 `video_recording_setup.md` 4절 참조)
- **배경음악(BGM)은 제외하기로 확정했습니다(9/5)** — 10/10이 시간압박이 가장 큰 날이라, 데모영상은 화면+설명이 핵심이지 BGM 없어도 무방합니다
- **자막은 자동생성 기능부터 써보기** — Clipchamp에도 자동 자막 기능이 있어서, 완벽하지 않아도 초안으로 쓰고 수정만 하면 훨씬 빠릅니다

## 5. 시간 배분 참고

- 녹화(10/9): 실제 촬영 자체는 1~2시간이면 충분(장면별로 끊어 찍으면)
- 편집(10/10): 자막/전환만 입히는 수준이면 1~2시간이면 충분

**너무 퀄리티에 압박받지 마세요** — 데모 영상은 "화면이 잘 보이고 설명이 명확한지"가 핵심이지, 화려한 편집이 핵심이 아닙니다.
