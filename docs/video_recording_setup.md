### 마이크 필터 3종 (순서 중요)

```
소음억제(RNNoise) → 노이즈게이트(폐쇄 -40 / 개방 -35) → 컴프레서
```

**순서 근거**: 컴프레서를 게이트보다 먼저 두면 배경소음까지 증폭시켜
게이트가 깔끔하게 못 자른다. **신호를 먼저 정리(억제) → 언제 마이크를
열지 결정(게이트) → 볼륨 다듬기(컴프레서)** 순서가 표준이다.
(9/5 크로스체크로 원래 순서 오류를 발견·수정함)

## 2. 편집 도구 — Clipchamp 확정 (9/5 크로스체크 완료)

**확정 근거**
- Windows 11 내장
- 무료 1080p, 워터마크 없음
- 로컬 파일 직접 편집(업로드 없음)

**배제된 도구와 이유**

| 도구 | 배제 이유 |
|---|---|
| Canva | 단일 영상 파일 **1GB 하드캡**(무료·Pro 유료 동일, Canva 공식 도움말로 확인함). 1080p 10분 이상 녹화본은 **업로드 자체가 거부됨** |
| VEED.io | 무료판 워터마크 + 720p + 10분 제한 |

**백업 도구: Shotcut** (OpenShot 아님 — 대용량/장시간 프로젝트 크래시 이력)

## 3. Clipchamp 사용 시 주의사항

- 공식 권장 프로젝트 길이 **10분 이하**. 초과 시 내보내기 실패/지연 사례 있음
- 프리미엄(다이아몬드 아이콘) 폰트·전환·스톡을 **하나라도** 쓰면 내보내기 차단됨
- 원본 파일 참조 방식이라 편집 중 원본을 옮기거나 이름 바꾸면 안 됨
- 내보내기 중 다른 창으로 전환 금지 (백그라운드로 밀리면 중단됨)

## 4. 10/7~10/10 실행 계획

- **영상 목표 길이: 10분 내외**
- **통짜 녹화 금지.** 시연 구간별 분할 녹화:
  - 로그인 + 대시보드
  - 예약생성
  - AI 게스트응대
  - 청소 + 정산

  구간당 3~4분 → NG 시 해당 구간만 재촬영, Clipchamp 안전권 유지
- **녹화 전 준비**
  - Windows 집중지원 켜기
  - 브라우저 북마크바 숨기기
  - 확대율 100% 확인
  - 시연용 더미데이터 미리 입력
- **마이크 교체 검토**: 현재 노트북 내장 "마이크 배열" → 유선 헤드셋 / USB 마이크 권장
- **10/7 필수**: 10분 더미 영상으로 **Clipchamp 내보내기 테스트 1회**.
  실패 시 Shotcut으로 전환 (10/10 당일에 알면 늦음 — 체크리스트에 이미
  게이트로 등록됨)
