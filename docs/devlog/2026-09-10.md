### 오후 — iCal 연동 구현 (r46, `473ed65` `bdc02ac` `535f415`)

엔드포인트 5종. **모델 변경도 alembic 마이그레이션도 필요 없었다** —
`last_error_message`가 v1.3에 이미 있었다.

```
GET    /properties/{property_id}/channels
POST   /properties/{property_id}/channels
DELETE /channels/{connection_id}
POST   /channels/{connection_id}/sync
GET    /channels/{connection_id}/sync-errors
```

`PATCH`는 만들지 않았다 — api_contract 3절이 URL 변경을 **DELETE 후 POST**로
규정한다(원문을 되돌려주는 엔드포인트를 두지 않기 위함). 응답은
`ical_url_masked`로만 내리고, 마스킹이 적용되는 생성 경로를 `from_model()`
하나로 묶었다.

**규칙 11 방어 3겹**: 타임아웃 5초 / 응답 크기 상한 2MB / 모든 실패를
`IcalSyncError` 하나로 좁힘. 이벤트 1건의 결함은 그 건만 건너뛴다
(Graceful Degradation). 예외 메시지에 URL·스택트레이스·호스트명을 담지
않는다 — 그대로 `last_error_message`에 저장돼 화면에 보이기 때문이다.

**인증 스텁 + 안전장치 3중**

JWT가 아직 없어 라우터가 `host_id`를 얻을 수단이 없다. 얻는 경로만
`get_current_host_id()` 하나로 격리하고 9/11에 본문만 교체한다.

| # | 장치 |
|---|---|
| 1 | `DEV_AUTH_HOST_ID` 환경변수를 읽는다. **기본값 없음** |
| 2 | `ENV`가 `development`가 아니면 **기동 자체 실패**(요청 시점이 아니라 기동 시점) |
| 3 | 스텁 활성 시 기동 경고 로그 |

`ENV` 기본값을 **`production`**으로 뒀다 — 환경변수를 빠뜨린 배포가 개발
환경으로 오인되지 않는 방향(fail-safe)이다.

### 오후 — asyncpg 제약명 판정 (troubleshooting **32번**, `00ade49` `a7c2567`)

**테스트 18건이 통과하는데 코드가 틀렸다.**

원인: SQLAlchemy가 asyncpg 예외를 자체 DBAPI 예외로 번역하며 `sqlstate`만
옮기고 **제약명은 메시지 문자열에만 남긴다.** `getattr(orig,
"constraint_name", "")`가 항상 `""`라 분기가 결코 참이 되지 않았다.

```
orig type       : IntegrityError   ← asyncpg의 UniqueViolationError가 아니다
sqlstate        : '23505'
constraint_name : 속성 없음 (dir()에 제약 관련 항목 0개)
str(orig)       : ... unique constraint "uq_property_channel"
```

**18건이 통과한 이유**: 전부 서비스 레이어를 거치기 때문이다.
`validate_unit_hierarchy()`와 Pydantic 검증이 잘못된 조합을 **DB에 닿기
전에** 막아 제약명 분기가 **한 번도 실행되지 않았다.** 동시성 상황의
마지막 방어선에서만 드러난다.

**수정 전 실패를 먼저 확인했다.** 애플리케이션 레이어를 의도적으로 우회해
모델을 직접 `add`·`flush`하는 테스트를 짜고, **수정 전 코드에서 2건이
실패하는 것을 본 뒤** 고쳤다.

```
E  AssertionError: 계층 FK 위반이 번역되지 않았다: ResourceNotFoundError
E  AssertionError: CHECK 위반이 번역되지 않아 500이 된다: IntegrityError
```

실패 메시지가 진단과 정확히 일치했다. `violates_constraint()`를
`app/utils/db_errors.py`로 옮겨 두 서비스가 공유한다(`channel_service`가
이미 `reservation_service`를 import해 역방향은 순환이 된다).

**30·31·32번이 같은 계열이다 — "초록불인데 틀렸다"**
